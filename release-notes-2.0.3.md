# Berrygram 2.0.3

- Меню ефектів більше не створює знімок для розмиття в режимі «Без ефектів». Це виправляє збій, який виникав, коли після вибору «Без ефектів» меню відкривали ще раз.
- «Без ефектів» залишає непрозорі поверхні кольорів поточної теми. Шпалери розмови не змінюються.
- У новій панелі «Назад», назва зі статусом та аватар розділені. Коли голосовий дзвінок доступний, він і аватар мають одну капсулу. Штатне меню розмови можна відкрити через **Відомості → ⋯ → Дії чату**. Якщо чат не має екрана відомостей, його штатні дії залишаються в панелі.
- «Нова верхня панель чату» — один перемикач у налаштуваннях чатів. Він зберігає попередній вибір стилю й не змінює режим ефектів. Коли його вимкнено, використовується класична панель.

APK: ARM64, Android 10 або новіший. Пакет `org.berrygram.client` і ключ підпису не змінені.
