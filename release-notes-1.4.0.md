# Berrygram 1.4.0 Stable

Це стабільний реліз лінії 1.4.0. Він замінює 1.4.0 Beta 1, Beta 2 і RC1 та встановлюється поверх
них без видалення застосунку й без втрати акаунтів, налаштувань та локальних баз.

- Package: `org.example.forkclient`
- Версія: `1.4.0`, versionCode `72759` (arm64) — вище за Beta 1 (72719), Beta 2 (72739) і RC1 (72749)
- АБІ: `arm64-v8a`, minSdk 23, targetSdk 36
- Підпис: той самий release-ключ, що й в опублікованому Stable 1.3.0 (сертифікат SHA-256 `b3ea9ca2…c722a5`)

## Що нового у 1.4.0

### Виправлено вбудоване оновлення
- **Стабільний реліз більше не пропонується як «оновлення» для бета-збірки.** Раніше власник бачив
  Update Center, який пропонував відкат (напр. 1.3.0 для встановленого 1.4.0-beta.2), а встановлювач
  відхиляв такий пакет. Тепер стабільний реліз пропонується лише тоді, коли він належить тій самій
  мінорній лінії, що й встановлена збірка (1.4.0 для 1.4.0-rc.1).
- **Канал оновлень залежить від встановленої збірки:** pre-release збирається автоматично на каналі
  Beta, стабільна — на Stable. Перемикання каналу одразу запускає повторну перевірку.
- **Контрольна сума** тепер береться з файлу `SHA256SUMS` релізу, коли GitHub API не повертає
  `digest` для ассета; реліз без будь-якої перевірної суми не пропонується.
- **Ліміт запитів GitHub** показується окремим повідомленням замість незрозумілої помилки HTTP.
- Дублікати ассетів у релізі відхиляються, показується versionCode встановленої збірки, а перевірка
  більше не позначається як «перерване завантаження».
- **Виправлено текст Update Center:** рядки були зі спотвореними символами («Youâ€™re up to date.»).

### Видалені повідомлення
- Текст видаленого повідомлення зберігається локально в момент видалення, тому «прозорий бульбас»
  (≈38 % альфи, читабельний текст, позначка видалення) **переживає перезапуск застосунку** і
  повертається на своє місце в чаті.

### Історія редагувань
- Попередня версія повідомлення визначається детерміновано (кеш останнього тексту), а не читанням
  бази після оновлення, тому версії не губилися при швидких редагуваннях. Однакові версії не
  дублюються.

### Ghost Mode
- Прихованість поширена на вторинні серверні сигнали читання: згадки, реакції та прочитаний вміст.
- Явна дія «Позначити як прочитане» **не приховується** ніколи. Секретні чати та TTL не змінені.

### Berry Archive
- Читання, пошук і завантаження архіву виконуються поза UI-потоком, пошук має затримку 250 мс.
- Налаштування приватності зберігаються окремо для кожного акаунту, старі глобальні переносяться
  автоматично.
- Додано термін зберігання: 7 / 30 / 90 днів або безстроково, з прибиранням під час запуску.
- Контент архіву, історії редагувань і позначок видалених зберігається в AES-GCM з ключем
  Android Keystore, прив'язаним до акаунту.

### Сповіщення та діагностика
- Екран «Сповіщення та діагностика» показує дозвіл, канали, реєстрацію push, фонові обмеження та
  локальний тест сповіщення.
- Збірка може підхопити **власний** Firebase-конфіг власника (`.fork-local/google-services.json`),
  жодні чужі ключі не використовуються і нічого не потрапляє в Git.

### Інше
- Профіль продуктивності Low додатково зупиняє вбудований круглий відеоперегляд; екран пояснює,
  що саме він змінює.
- Виправлено некоректне екранування апострофів у рядках, через що release-збірка ресурсів могла
  падати.

## Відомі обмеження

- **Віддалений push (FCM) не працює без власного Firebase-проєкту Berrygram.** Потрібні поля
  `google_app_id`, `gcm_defaultSenderId`, `project_id`, `google_api_key` для package
  `org.example.forkclient`. Поки конфігурації немає, Telegram не надсилає push на сторонній
  пакет і сповіщення надходять лише коли процес застосунку живий. Діагностика чесно показує стан
  `push_not_configured`. Локальне тестове сповіщення не є доказом роботи віддаленого push.
- **Немає перевірки на реальному пристрої** (ADB: 0 пристроїв, емулятор не стартує). Перевірено
  автоматизовано: компіляція, unit та інтеграційні тести, живий GitHub API, верифікація завантаженого
  опублікованого APK.
- Архів містить лише повідомлення, побачені на цьому пристрої; історичний імпорт — план 1.4.1.
- Швидка кнопка Ghost Mode, новий дизайн налаштувань, теми OLED/AMOLED, Glass 3.0, Berry UI,
  кастомна клавіатура, Berry Graphics і плагінна система — це 1.4.1–1.5.x, не входять у цей реліз.

## Оновлення

- Стабільний канал: застосунок знайде `1.4.0` автоматично.
- Beta-канал: застосунок знайде `1.4.0` після того, як з'явиться pre-release з вищою версією.
- Оновлення виконується штатним Android Package Installer, без root і без видалення застосунку.
