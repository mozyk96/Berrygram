# Berrygram 1.4.0 RC — ручний тест на пристрої

APK: `BerryGram-1.4.0-rc.1-arm64-v8a.apk` · package `org.example.forkclient` · versionCode `72749`
Сумісність: встановлення поверх 1.4.0 Beta 2 (72739) або Stable 1.3.0 (72639) без видалення
даних, підпис той самий (`CN=BerryGram Release`).

## 1. Встановлення та збереження даних

- [ ] Встановити APK поверх наявної Berrygram (не видаляти стару версію).
- [ ] Перевірити, що залогінений акаунт, чати, налаштування та історія редагувань на місці.
- [ ] Перевірити, що бази `fork_archive_*`, `fork_deleted_messages_*`, `fork_edit_history_*`
      пережили оновлення (наявність старих записів у Berry Archive).

## 2. Сповіщення (найважливіше)

- [ ] Прийти повідомлення в застосунок, **закритий** (згорнути), екран вимкнений.
- [ ] Прийти повідомлення з **закритою** програмою (Androidkiller не застосовувати).
- [ ] Перевірити приватне повідомлення, повідомлення в групі, згадку (@) та відповідь.
- [ ] Перевірити другий акаунт (сповіщення приходять у правильному акаунті).
- [ ] Перевірити вимкнені сповіщення в чаті та заблокований канал.
- [ ] Відкрити **Налаштування → Berrygram → Сповіщення та діагностика**:
      стан дозволу, стан каналів, стан push-реєстрації, фоновий режим, локальний тест.
- [ ] Якщо push показує «Не налаштовано в цій збірці» — це очікувано: потрібен власний
      Firebase-проєкт (див. інструкцію нижче). Тоді сповіщення приходять лише поки
      процес застосунку живий.

### Як додати власний Firebase (для повного push)

1. Firebase Console → створити проєкт → Android-додаток із package name `org.example.forkclient`.
2. Завантажити `google-services.json`.
3. Покласти його в `.fork-local/google-services.json` у проєкті (файл НЕ комітити).
4. Перебудувати: `gradlew :TMessagesProj_App:assembleAfatRelease -PforkAbi=arm64-v8a`.
5. У діагностиці push має показати «Зареєстровано».

## 3. Ghost Mode (Привид-читання)

- [ ] Увімкнути Ghost Mode + окремо для приватних чатів і для груп.
- [ ] Відкрити чат — відправник **не має** бачити статус прочитання.
- [ ] Натиснути «Позначити як прочитане» в списку чатів — статус **має** змінитися (виняток із прихованості).
- [ ] Перевірити, що згадки та реакції теж не надсилають сигнал прочитання.
- [ ] Перезапустити застосунок — налаштування збереглися, поведінка та сама.
- [ ] Перевірити секретний чат: читання працює як завжди (приховування не застосовується).

## 4. Видалені повідомлення

- [ ] Увімкнути «Зберігати видалені повідомлення» в Berry Privacy.
- [ ] Видалити повідомлення у чаті (власне) — воно лишається на місці з ~38 % прозорим бульбасом,
      текст читається, є позначка видалення.
- [ ] **Перезапустити застосунок і відкрити той самий чат** — видалений текст має лишатися на місці.
- [ ] Перевірити, що видалені повідомлення видно в Berry Archive з позначкою «видалено».

## 5. Історія редагувань

- [ ] Відредагувати власне повідомлення (змінити текст).
- [ ] Відкрити контекстне меню повідомлення → «Історія редагувань» — має показати попередню версію.
- [ ] Відредагувати ще раз — має бути видно обидві попередні версії з часом.
- [ ] Перезапустити застосунок — історія збереглася.
