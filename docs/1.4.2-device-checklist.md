# Berrygram 1.4.2 — ручний тест на пристрої

APK: `BerryGram-1.4.2-arm64-v8a.apk` · package `org.example.forkclient` · versionCode `72789`
Сумісність: встановлення поверх 1.4.1 (72779) або 1.4.0 (72759) без видалення даних,
підпис той самий (`CN=BerryGram Release`, SHA-256 `b3ea9ca2…c722a5`).

Цей цикл виправляє дефекти, які власник побачив на реальному телефоні: налаштування
не були справді об'єднані, у Performance Center показувався `LOC_ERR:null`, перемикання
вкладок смикалося, а вміст заходив під нижню навігацію.

## 1. Встановлення та збереження даних

- [ ] Встановити APK **поверх** наявної Berrygram, не видаляти стару версію.
- [ ] Перевірити, що залогінений акаунт, чати, усі налаштування, архів і історія
      редагувань залишилися на місці.
- [ ] Перевірити, що версія в Налаштуваннях показує `1.4.2`.
- [ ] Переконатися, що в Berrygram Archive старі записи на місці.

## 2. Єдині налаштування (головна перевірка)

- [ ] У корені Налаштувань **немає** окремих пунктів «Berrygram Effects», «Media and Input»,
      «Berrygram Privacy», «Notification Diagnostics», «Berrygram Archive», «Performance».
- [ ] У корені лишився один Berrygram-пункт — **«Центр оновлень»** у розділі «Довідка»;
      він відкриває версію, відомості про застосунок і оновлення.
- [ ] **Параметри чату** (Chat Settings) містять блок Berrygram: стиль ефектів, радіус кутів,
      «Розширені анімації», «Реакції», «Меню повідомлень», «Власний текст», а також
      «Жести», «Відеоповідомлення», «Голосові повідомлення».
- [ ] **Приватність і безпека** містять блок Berrygram: Ghost Mode (_private/групи),
      «Зберігати видалені повідомлення», «Історія редагувань», «Показувати в меню»,
      «Увімкнути архів» і «Термін зберігання».
- [ ] **Сповіщення** містять блок «Діагностика» з єдиним пунктом на перевірку сповіщень.
- [ ] **Дані та пам'ять** містять блок «Архів» (відкрити архів, створити/оновити архів).
- [ ] **Мова** містить блок «Переклад» (автоматичний переклад, цільова мова).
- [ ] **Енергозбереження** містить блок «Продуктивність» (режим конфігурації, ручний
      рівень, Mini Dock).
- [ ] Перемикачі всіх блоків змінюють стан і зберігають його після перезапуску.
- [ ] Натиснути «Назад» з кожного блоку: повернення на той самий екран Telegram.

## 3. `LOC_ERR:null`

- [ ] **Енергозбереження → Продуктивність**: жоден рядок не показує `LOC_ERR:null`
      (режим конфігурації, системний режим енергозбереження, анімації, зменшення ефектів).
- [ ] Перевірити ті самі рядки в українській, англійській та російській мовах.
- [ ] Перевірити «Центр оновлень», «Приватність і безпека», «Мова», «Дані та пам'ять»,
      «Параметри чату» — усі підписи заповнені, без `LOC_ERR` і без порожніх рядків.
- [ ] Увімкнути розмір шрифту 130 %: підписи не обрізаються, рядки не накладаються.

## 4. Нижня навігація

- [ ] Натискати кожну вкладку (Чати, Контакти, Дзвінки/Налаштування, Профіль):
      індикатор рухається разом зі сторінкою, без стрибків і подвійної анімації.
- [ ] Потягнути пальцем між вкладками й **відпустити назад** (скасований свайп):
      індикатор повертається рівно під активну вкладку.
- [ ] Швидко перемикати вкладки 5–6 разів: без мерехтіння та «стрибків» назад.
- [ ] Увімкнути/вимкнути вкладку Дзвінків: індикатор лишається під правильною вкладкою.
- [ ] Повернутися з чату назад: активна вкладка та індикатор збігаються.
- [ ] Повернути телефон (обертання): індикатор на місці.
- [ ] Залишити застосунок на одній вкладці 15 с: смуга не перемальовується постійно.

## 5. Розмітка та відступи

- [ ] У **кожному** екрані налаштувань (Параметри чату, Приватність, Сповіщення,
      Дані, Мова, Енергозбереження) останній рядок повністю видимий і прокручується
      вище нижньої навігації.
- [ ] Те саме для Berrygram-екранів: «Центр оновлень», «Продуктивність», «Переклад»,
      «Архів», «Ефекти».
- [ ] Перевірити на телефоні з gesture-навігацією та з трьома кнопками.
- [ ] Перевірити в темній і світлій темі: картки мають однаковий радіус, натиснутий
      рядок не стає прямокутним.

## 6. Архів (повторна перевірка після правок потоків)

- [ ] Berry Archive → «Створити архів»: вибрати один чат, кілька чатів і «Вибрати все».
- [ ] Під час імпорту показується прогрес із назвою поточного чату; «Скасувати»
      зупиняє імпорт за кілька секунд.
- [ ] Після імпорту запустити ще раз: дублікатів немає, нові повідомлення додаються.
- [ ] Перервати імпорт і запустити знову: робота продовжується з місця зупинки.
- [ ] Під час імпорту прийняти вхідне повідомлення: застосунок не підвисає (запис
      архіву більше не йде на UI-потоку).
- [ ] «Очистити архів» завершується без помилки, список оновлюється.
- [ ] Відкрити архівований чат: повідомлення видно, падіння немає.
- [ ] Перевірити другий акаунт: його архів порожній, дані не змішуються.

## 7. Переклад

- [ ] Мова → блок «Переклад»: вибрати цільову мову, у рядку видно **назву мови**.
- [ ] Відкрити звичайний чат: обрана мова застосовується.
- [ ] Автоматичний переклад вмикається лише коли його увімкнено; секретні чати й
      «Обране» не перекладаються автоматично.

## 8. Ghost Mode, видалені повідомлення, історія редагувань

- [ ] Ghost Mode вмикається/вимикається в Приватності; стан зберігається окремо
      для кожного акаунта.
- [ ] Видалені повідомлення лишаються після перезапуску й видні в архіві.
- [ ] Історія редагувань показує попередні версії.

## 9. Загальна стабільність

- [ ] Прокрутити довгий список чатів і кілька довгих чатів: без ривків.
- [ ] Прогрес імпорту не губиться, коли застосунок згорнути й розгорнути.
- [ ] Перевірити пам'ять після великого імпорту.

## 10. Якщо застосунок впав

```bash
adb logcat -c
adb logcat -v time AndroidRuntime:E ActivityManager:E Telegram:E *:S
# відтворити падіння, потім:
adb logcat -d -v time > crash-142.log
adb shell dumpsys meminfo org.example.forkclient > meminfo-142.txt
```

Надіслати `crash-142.log` — у ньому видно стек винятку AndroidRuntime.

## 11. Відомі обмеження цієї збірки

- Remote push (FCM) не налаштований: діагностика показує `push_not_configured`.
- На цьому хості немає ADB-пристрою чи емулятора, тому **жоден** пункт вище не
  перевірено на реальному телефоні. Автоматичні перевірки (компіляція Kotlin/Java,
  smoke-тести, регресія локалізації, інспекція й підпис APK) пройдено, але плавність
  анімацій і реальна поведінка UI потребують ручного підтвердження.
- Інструментальні тести (`ForkLocalizationInstrumentationTest`,
  `ForkSettingsInstrumentationTest`) додано в `TMessagesProj_AppTests`; їх можна
  запустити на пристрої або в емуляторі:
  `.\gradlew :TMessagesProj_AppTests:connectedAfatDebugAndroidTest`.
