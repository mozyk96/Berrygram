## Appearance modes (owner-facing)

- No Background (Без фону / Без фона): no header plate, no composer island
  plate, no bottom-tabs plate. Popups stay on opaque material for legibility.
  `PanelPolicy.isBackgroundless` compares the literal `none` style, so the
  opaque `material` fallback is never misread as No Background.
- Blur: the existing progressive backdrop blur drawable.
- Liquid Glass: the existing glass renderer. No user-visible "Glass 3.0".

`LiteMode.toggleFlag(FLAG_LIQUID_GLASS, true)` now keeps an already selected
glass style instead of rewriting it, and power saving no longer downgrades an
explicit `none` style.
