# Berrygram 1.4.1 RC — ручний тест на пристрої

APK: `BerryGram-1.4.1-rc.1-arm64-v8a.apk` · package `org.example.forkclient` · versionCode `72769`
Сумісність: встановлення поверх 1.4.0 Stable (72759) без видалення даних, підпис той самий
(`CN=BerryGram Release`, SHA-256 `b3ea9ca2…c722a5`).

## 1. Встановлення та збереження даних

- [ ] Встановити APK поверх наявної Berrygram 1.4.0 (не видаляти стару версію).
- [ ] Перевірити, що залогінений акаунт, чати, налаштування, архів і історія редагувань на місці.
- [ ] Відкрити Berry Archive: старі записи видно, нові не зникли після оновлення.
- [ ] Перевірити, що версія в Налаштуваннях показує `1.4.1-rc.1`.

## 2. Нижня навігація

- [ ] Натискати кожну вкладку (Чати, Контакти, Налаштування/Дзвінки, Профіль): індикатор
      рухається синхронно з пейджером, без стрибків і подвійних анімацій.
- [ ] Потягнути пальцем між вкладками й **відпустити назад** (скасований свайп): індикатор
      повертається рівно під активну вкладку.
- [ ] Довге натискання на вкладку: індикатор не «залипає» і не зміщується.
- [ ] Вимкнути вкладку Дзвінки в налаштуваннях: індикатор лишається під правильною вкладкою.
- [ ] Увімкнути зменшення анімацій у системі: індикатор не розтягується, рух лишається коректним.
- [ ] Залишити застосунок на одній вкладці 10–15 с: немає постійного перемальовування смуги
      (візуально й за відсутністю нагріву/витрати батареї).

## 3. Єдині налаштування

- [ ] У головних Налаштуваннях **немає** окремого верхнього пункту «Berrygram».
- [ ] Berrygram-пункти стоять одразу після відповідних розділів Telegram:
      Приватність, Вигляд, Мова, Сповіщення, Дані та пам'ять, Енергозбереження.
- [ ] Розділ Вигляд містить два Berrygram-пункти в сталому порядку (ефекти, потім медіа).
- [ ] Пункт «Про Berrygram» стоїть над рядком версії та відкриває версію/Центр оновлень.
- [ ] Старий екран Berrygram (якщо відкрити з історії/посилання) перенаправляє в єдині налаштування.
- [ ] Перевірити світлу й темну тему: заголовки, підписи та іконки читаються.

## 4. Швидкий Ghost Mode

- [ ] У списку чатів натиснути кнопку привида на панелі: майстер-перемикач Ghost Mode
      вмикається/вимикається, кнопка показує стан.
- [ ] Перевірити, що стан зберігається після перезапуску й **окремо для кожного акаунта**.
- [ ] Довге натискання на кнопку відкриває налаштування Stealth.
- [ ] Увімкнений Ghost Mode: відкриття чату не надсилає статус прочитання.
- [ ] «Позначити як прочитане» в списку чатів працює навіть із увімкненим Ghost Mode.
- [ ] Секретні чати й TTL-контент поводяться як звичайно.

## 5. Імпорт історії в архів

- [ ] Berry Archive → «Створити архів»: вибрати один чат, кілька чатів і «Вибрати все».
- [ ] Перевірити, що секретні чати **відсутні** у списку вибору.
- [ ] Під час імпорту показується прогрес із назвою поточного чату; «Скасувати» зупиняє
      імпорт протягом кількох секунд (навіть під час FLOOD_WAIT).
- [ ] Після завершення показано підсумок із кількістю імпортованих повідомлень.
- [ ] Запустити імпорт ще раз: уже наявні повідомлення не дублюються, нові додаються.
- [ ] Перервати імпорт і запустити знову: робота продовжується з місця зупинки, без повторного
      проходження вже оброблених сторінок.
- [ ] Чат із понад 100 новими повідомленнями після першого імпорту: «Оновити архів» додає весь
      проміжок, а не лише останню сторінку.
- [ ] «Очистити архів», потім створити заново: історія імпортується з нуля (курсори скинуто).
- [ ] Видалити один чат з архіву й імпортувати його знову: повідомлення повертаються.
- [ ] Службові повідомлення та контент без тексту не потрапляють в архів.

## 6. Переклад

- [ ] Налаштування → Мова → Berrygram: вибрати цільову мову; у рядку показується **назва мови**,
      а не технічний код.
- [ ] Відкрити звичайний чат: обрана мова застосовується до перекладу в цьому чаті.
- [ ] Увімкнути «Автоматично перекладати чати»: новий чат відкривається з уже увімкненим
      перекладом через сервіс Telegram.
- [ ] Вимкнути автоматичний переклад: нові чати не вмикають переклад автоматично.
- [ ] Секретний чат і «Обране»: переклад ніколи не вмикається автоматично.
- [ ] Перевірити, що використовується штатний переклад Telegram, без сторонніх сервісів.

## 7. Продуктивність і стабільність

- [ ] Прокрутити список чатів і кілька довгих чатів: без ривків і зависань.
- [ ] Імпорт 2–3 чатів поспіль: застосунок лишається чутливим, без ANR.
- [ ] Відкрити/закрити архів, пошук в архіві, видалені повідомлення: без помилок.
- [ ] Згорнути й розгорнути застосунок під час імпорту: прогрес не губиться.
- [ ] Перевірити пам'ять після великого імпорту (немає різкого зростання до перезапуску).

## 8. Регресії 1.4.0

- [ ] Центр оновлень: перевірка оновлень, обидва канали, коректна версія.
- [ ] Видалені повідомлення: лишаються після перезапуску, видно в архіві.
- [ ] Історія редагувань: попередні версії з часом.
- [ ] Ghost secondary reads: згадки/реакції не надсилають прочитання.
- [ ] Окремі налаштування для другого акаунта.
- [ ] Українські/російські рядки без «кракозябр» і без зламаних escape-послідовностей.

## 9. Відомі обмеження цієї збірки

- Remote push (FCM) не налаштований: немає власного Firebase-проєкту Berrygram. Діагностика
  показує `push_not_configured`; сповіщення працюють, поки процес застосунку живий.
- На цьому хості немає ADB-пристрою чи емулятора, тому всі пункти вище — **не перевірені
  на пристрої**. Автоматичні перевірки (компіляція, smoke-тести, підпис, ABI, alignment)
  пройдені, але плавність анімацій і реальна поведінка UI потребують ручного підтвердження.
- Імпорт обмежений доступною історією та лімітами одного запуску (до ~2000 повідомлень і
  50 сторінок на чат); повторний «Оновити архів» продовжує роботу.
